# BIM Guard documentation

> Guides for BIM Guard: getting started, projects, documents and rule extraction, running compliance audits, reports and administration.

BIM Guard checks IFC building models against architectural code rules, tracks the results as BCF issues and reports, and keeps project documents under ISO 19650 governance.

## Typical workflow

- Create a **project** and attach an IFC model.
- Upload a code **document** and extract **rules** from it, or pick an existing ruleset.
- Run a **compliance audit**.
- Review results, the 3D view, and **reports and exports** (BCF, PDF, Excel, CSV).
