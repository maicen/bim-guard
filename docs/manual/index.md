# BIM-Guard User Manual

BIM-Guard analyzes IFC building models for corrosion risk and ISO 19650 / CDE compliance, and lets your team manage projects, documents, and compliance rules in one place.

This manual covers:

- **[Getting Started](getting-started.md)** — installing, running the app, and signing in for the first time.
- **Projects** — creating a project and configuring its settings.
- **Infrastructure Setup** — environment variables, Supabase, and deployment.
- **Documents** — uploading and managing project documents.
- **Rules** — browsing and managing the compliance rules catalog.
- **Analysis** — running an IFC analysis and reading the results.
- **Administration** — managing users and organizations.

!!! note "Who this is for"
    This manual is written for system users, admins, and project owners operating BIM-Guard day to day — not for developers extending the codebase. See the repository's `README.md` and `CLAUDE.md` for developer-facing documentation.
