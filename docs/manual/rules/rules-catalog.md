# Rules Catalog

The **Rules** view lists all compliance rules used during analysis, sourced from the database — nothing is hardcoded, so edits here take effect on the next analysis run without a server restart.

Rule families include:

- **`ARCH-EGRESS-001`** — Means-of-egress compliance
- **`ARCH-SPATIAL-001`** — Spatial/clearance compliance
- ISO 19650 governance and CDE-state rules

## Working with rules

- Search, filter, and sort the catalog like any other data table.
- Select a **ruleset** (`rule_folder`) per project to scope which rules apply.
- Import/export rules via the menu in the top-right of the Rules view.
