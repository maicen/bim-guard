# Uploading Documents

1. Open the project you want to add a document to.
2. Go to **Documents** and select **Upload**.
3. Choose one or more PDF files. BIM-Guard extracts and indexes the text automatically for review and rule matching.
4. Each uploaded document is assigned ISO 19650 metadata (originator, type, suitability code, revision code, CDE state) — review and correct this before publishing.
5. Documents start in the `WIP` CDE state and move through `SHARED` → `PUBLISHED` → `ARCHIVED` as they're reviewed and approved.

## Managing uploaded documents

The Documents table supports:

- Multi-select and bulk actions (bulk delete, bulk export)
- Search and filtering
- Sorting by column
- Opening a document's details to review extracted text and metadata
