Workflow

1. Create a project with the wizard and attach one IFC model.
2. Add specification PDFs, here or from the Library.
3. Extract rules, or use a shipped rule pack.
4. Run the analysis against a theme.
5. Export before navigating away.

Known limits

• Analysis results do not persist across requests.
• One IFC per project.
• MM-001 and XM-001 do not load their packs.
• No authentication or per-user separation.
• Exports are process-global.

The Navisworks platform offers a Uniclass 2015 naming convention but never populates {classA} or {classB} — both are hardcoded empty, so Uniclass names emerge with two blank segments.
